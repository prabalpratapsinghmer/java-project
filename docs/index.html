System Highlights & Engineering Principles

Designed for academic excellence, strict data integrity, and demonstrable OOP rigor.

🛡️

PBKDF2 Cryptography

Zero plaintext persistence. Uses PBKDF2WithHmacSHA256 with 16-byte random salts and 65,536 iterations for secure student, admin, and technician passwords.

🔄

Intelligent Duplicate Detection

Normalizes location punctuation and searches active complaints within a 7-day rolling window to warn students before creating duplicate work orders.

⚡

Deterministic Priority

Transparent, explainable mathematical rule: Base severity (1-3) plus category risk bonus (+1 for Electrical/Safety) clamped at 4 (Critical).

💾

Atomic File Persistence

All writes staged to temporary files before atomic file-system replacement via Java NIO. Corrupted records are safely isolated to .corrupt files.

📊

Injection-Safe CSV Export

RFC-4180 compliant CSV generator equipped with spreadsheet formula injection defense (mitigating =, +, -, @ execution vectors).

📝

Immutable Audit Trail

Chronological history of every state transition, technician assignment, work start, and completion notes encapsulated in unmodifiable collections.
